# covid-track

A React-based web application for exploring and visualizing COVID-19 statistics.

## Overview

COVID Track is a frontend project built around presenting COVID-19 data in an accessible, visual format. It uses React for the user interface and charting components to help communicate pandemic-related statistics.

## Tech Stack

- **React 17** — Component-based user interface
- **Material UI** — UI components and styling
- **Recharts** — Data visualization
- **Axios** — HTTP requests and API integration
- **Sass** — Application styling
- **React Window** — Efficient rendering of large lists
- **React Testing Library** — Component testing

## Getting Started

### Prerequisites

- Node.js 14.x
- npm

### Installation

Clone the repository:

```bash
git clone https://github.com/RodoMark/covid-track.git
cd covid-track
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm start
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Available Scripts

| Command | Description |
|---|---|
| `npm start` | Start the development server |
| `npm run build` | Create a production build |
| `npm test` | Run the test suite |

## Project Background

COVID Track was developed as a frontend application focused on communicating public-health data through a React interface.

The project reflects a React 17-era technology stack and is preserved as an example of frontend application development.

## Disclaimer

This is a historical project. COVID-19 information displayed by the application should not be assumed to reflect current public-health conditions.
